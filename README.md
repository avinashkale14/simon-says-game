# 🎮 Simon Says Game

A simple interactive Simon Says memory game built using HTML, CSS, and JavaScript.

---

## 🚀 Live Demo
https://simon-says-ak.vercel.app/

---

## 📌 Features
- Random color sequence generation
- Level progression
- Game over detection
- Visual flash effects
- Responsive UI

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (DOM Manipulation)

---

## 🎯 How to Play
1. Click "Start Game"
2. Watch the flashing color sequence
3. Repeat the sequence by clicking the buttons
4. Each level adds a new color to remember
