# 🎮 Simon Says Game

An interactive memory-based Simon Says game built using **HTML, CSS, and JavaScript**.  
This project demonstrates DOM manipulation, event handling, and game logic implementation using vanilla JavaScript.

---

🔗 https://simon-says-ak.vercel.app/

## 🚀 Features

- 🎯 Random color sequence generation
- 📈 Progressive difficulty (level-based gameplay)
- ⚡ Visual flash animations
- 🧠 Memory sequence validation logic
- ❌ Game over detection with score display
- 🔄 Restart functionality
- 📱 Responsive layout

---

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling & animations
- **JavaScript (ES6)** – Game logic & DOM manipulation

---

## 🎮 How to Play

1. Click the **Start Game** button.
2. Watch the flashing color pattern.
3. Repeat the pattern by clicking the colored buttons.
4. Each level adds a new color to the sequence.
5. If you press the wrong button — Game Over!

- Event Listeners
- DOM Selection & Manipulation
- Arrays & Sequence Tracking
- Conditional Logic
- setTimeout()
